## Featured projects

### [Altura Bank](https://github.com/RamsesJM/Altura-bank) · [Live demo](https://altura-bank.vercel.app)

Online banking front end: sign-in with lockout, inactivity sign-out that survives a locked phone, dashboard with a consolidated balance, transaction history with filters and CSV export, and transfers with quotes, one-time codes, daily limits and protection against double charges. Installable on phones.

`React 19` `TypeScript` `TanStack Query` `React Router` `Tailwind CSS` `MSW` `Vitest` `Testing Library` `GitHub Actions` `Vercel`

- 287 automated tests, run on every push and pull request; `main` only accepts changes with a green check
- All money math in whole cents; transfers carry an idempotency key so a retry never moves money twice
- A design document for every stage in `docs/specs`

### [TaskFlow](https://github.com/RamsesJM/task-manager)

Full-stack task manager with authentication, per-user tasks, priorities, due dates, search and filters, plus a token-protected REST API.

`Laravel` `PHP` `Blade` `Tailwind CSS` `SQLite` `Laravel Sanctum` `Pest`

- Authorization enforced on the server with Laravel Policies, not only in the interface

### [Dorée Nails](https://github.com/RamsesJM/doree-nails-landing)

Responsive landing page for a fictional nail salon, built without frameworks: collapsible navigation, gallery with a keyboard-friendly lightbox and a booking form that opens a pre-filled WhatsApp message.

`HTML` `CSS` `JavaScript`
